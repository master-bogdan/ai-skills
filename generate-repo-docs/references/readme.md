# README.md Contract

`README.md` is the fast first-contact document.

## Required Sections

- repo name and short purpose
- what the repo does
- prerequisites when they are discoverable
- setup
- run
- test and lint
- high-level project layout
- links to `AGENTS.md` and canonical docs

## Scope

Keep it short. Do not let it absorb navigation or deep architecture content.

## Style

- practical
- command-oriented
- brief
