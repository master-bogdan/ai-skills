# Go — Swagger Setup

## Tool and package setup

```sh
# Install swag CLI
go install github.com/swaggo/swag/cmd/swag@latest

# Install framework-specific swagger middleware
# For Gin:
go get github.com/swaggo/gin-swagger
go get github.com/swaggo/files

# For Echo:
go get github.com/swaggo/echo-swagger

# For Fiber:
go get github.com/swaggo/fiber-swagger
```

## Main entrypoint annotation

Add to the `main()` function or the top-level package doc:

```go
// @title           Orders API
// @version         1.0
// @description     API for managing orders
// @host            localhost:8080
// @BasePath        /api/v1
// @securityDefinitions.apikey BearerAuth
// @in header
// @name Authorization
func main() {
    // ...
}
```

## Route annotation format

Add annotations directly above handler functions:

```go
// ListOrders returns all orders for the authenticated user.
// @Summary     List orders
// @Description Get all orders for the current user
// @Tags        orders
// @Produce     json
// @Security    BearerAuth
// @Success     200 {array}  Order
// @Failure     401 {object} ErrorResponse
// @Router      /orders [get]
func (h *OrderHandler) ListOrders(c *gin.Context) {
    // ...
}

// CreateOrder creates a new order.
// @Summary     Create order
// @Tags        orders
// @Accept      json
// @Produce     json
// @Security    BearerAuth
// @Param       input body CreateOrderInput true "Order input"
// @Success     201 {object} Order
// @Failure     400 {object} ErrorResponse
// @Router      /orders [post]
func (h *OrderHandler) CreateOrder(c *gin.Context) {
    // ...
}
```

## Model annotation

Add to struct definitions:

```go
// Order represents a customer order.
type Order struct {
    ID        string      `json:"id" example:"ord-123"`
    Status    OrderStatus `json:"status" example:"pending"`
    Total     float64     `json:"total" example:"49.99"`
    CreatedAt time.Time   `json:"createdAt"`
}

// CreateOrderInput is the request body for creating an order.
type CreateOrderInput struct {
    Items []OrderItem `json:"items" binding:"required,min=1"`
}
```

## Middleware registration (Gin)

```go
import (
    ginSwagger "github.com/swaggo/gin-swagger"
    swaggerFiles "github.com/swaggo/files"
    _ "github.com/yourorg/yourapp/docs" // generated by swag — must import
)

router.GET("/docs/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
```

## Generate static files

```sh
# Run from project root
# -g: path to main.go or file with main package annotations
# -o: output directory
swag init -g cmd/server/main.go -o docs/
```

This generates:
- `docs/swagger.json` — OpenAPI spec
- `docs/swagger.yaml` — YAML version
- `docs/docs.go` — Go package (must be imported as `_ "yourapp/docs"`)

Add to `Makefile`:
```makefile
swagger:
	swag init -g cmd/server/main.go -o docs/
	go run scripts/extract-schemas.go
```

## Extract individual JSON schema files

After running `swag init`, extract per-model schemas from `docs/swagger.json`:

```go
// scripts/extract-schemas/main.go
package main

import (
    "encoding/json"
    "fmt"
    "os"
    "path/filepath"
)

func main() {
    data, _ := os.ReadFile("docs/swagger.json")
    var spec map[string]any
    json.Unmarshal(data, &spec)

    definitions, ok := spec["definitions"].(map[string]any)
    if !ok {
        fmt.Println("No definitions found")
        return
    }

    os.MkdirAll("docs/schemas", 0755)
    for name, schema := range definitions {
        out, _ := json.MarshalIndent(schema, "", "  ")
        os.WriteFile(filepath.Join("docs/schemas", name+".json"), out, 0644)
        fmt.Printf("Wrote docs/schemas/%s.json\n", name)
    }
}
```

## Framework detection

Check `go.mod` for the framework import:
- `github.com/gin-gonic/gin` → use `gin-swagger`
- `github.com/labstack/echo` → use `echo-swagger`
- `github.com/gofiber/fiber` → use `fiber-swagger`
- `net/http` only → use `httpSwagger` from `github.com/swaggo/http-swagger`
