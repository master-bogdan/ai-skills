# docs/how-system-works.md Contract

Explain how the important flows behave.

## Focus

Document the main execution paths such as:

- request handling
- startup and shutdown
- editor or UI flows
- save and sync flows
- background jobs
- event handling
- integration flows

## Structure

- short overview
- numbered flows
- simple text diagrams when useful
- brief explanation of why each flow matters

## Naming Rule

This file replaces `docs/runtime-flows.md` when that legacy file exists.
